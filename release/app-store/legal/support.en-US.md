## Common Setup Steps

- Allow microphone access when prompted.
- Allow speech recognition access when prompted.
- For the Fonos keyboard extension, enable Full Access in iOS Settings.
- Keep the Fonos app running when testing keyboard dictation.

## Keyboard Dictation

The Fonos keyboard extension communicates with the main Fonos app through an App Group. If keyboard dictation does not start, open the Fonos app first, then return to the app where you want to type and switch to the Fonos keyboard.

## Model Configuration

Fonos can use Apple Speech for dictation. You can also configure OpenAI-compatible speech-to-text and language model services in Settings by entering your own endpoint and API key.

API keys are stored in Keychain.
